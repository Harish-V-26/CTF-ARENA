# Instructions to Code

These instructions must be followed throughout the project:

1. **No Emojis**: Remove all emojis from the project and do not add any in the future.
2. **Beginner-Friendly Explanations**: Replace all detailed definitions with language that can be easily understood by someone who knows absolutely nothing about cybersecurity and is completely new to it.
3. **Structured Learning**: Every vulnerability/topic should have a detailed, simple explanation covering:
   - **What is it?** (A simple analogy or description)
   - **Why attack it?** (What is the hacker trying to achieve/what is the impact?)
   - **How is it used?** (How does the attack work in practice?)
