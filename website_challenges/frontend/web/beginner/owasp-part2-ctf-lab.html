Mission Briefing

AGENT, a high-value targets server running within an isolated Docker environment contains sensitive operational plans. Your mission is to compromise the server using a chain of vulnerabilities corresponding to categories 6 through 10 of the OWASP Top 10:

  • Mishandling of Exceptional Conditions (OWASP #10): Extract verbose diagnostic data that discloses system paths and db credentials.
  • Insecure Design (OWASP #6): Discover a hidden administrative path that was obscured rather than properly protected.
  • Authentication Failures (OWASP #7): Enumerate valid usernames and brute force the operator password.
  • Predictable Sessions (OWASP #7): Analyze session cookies, identify the signature mechanism, and forge an administrator token.
  • Software & Data Integrity Failures (OWASP #8): Submit unsigned, serialized configurations to achieve remote command execution (RCE).
  • Logging & Monitoring Failures (OWASP #9): Inject fake logging payloads to hide tracks or audit alert notifications.

Launch the target and the offensive terminal environment below, trace the vulnerabilities, and locate the master flag in /app/flag.txt.

Challenge Hints

Hint 1 — Verbose Errors & Secret Paths
Look closely at the landing page of the Target portal. There is a button to test the database connection status. If you click it, the system encounters an unhandled exception and spits out a verbose error traceback (OWASP #10). Read the traceback lines carefully — they disclose internal parameters, database passwords, and the path to a hidden login portal.
Hint 2 — User Enumeration & Authentication Bypasses
Once you navigate to the hidden path, analyze how the login interface behaves. Try common usernames like admin or guest. Does the error message change depending on whether a username exists in the system (OWASP #7)? Check if there's an account lockout limit. You can brute-force the password using the DB password leaked in Hint 1.
Hint 3 — Predictable Session Forgery
Log in as the low-privilege user guest with the password guestpassword. Look at the cookie set in your browser (DevTools -> Application -> Cookies). What is the cookie value? Run it through a hash identifier. It's just a simple MD5 hash of the username! Can you compute the MD5 of the administrator username sysadmin (e.g. using online tools or echo -n sysadmin | md5sum) and replace your cookie value with it to escalate privileges?
Hint 4 — Insecure Deserialization & RCE
Once logged in as sysadmin, you will find the admin dashboard. In the custom plugin loader (OWASP #8), the backend processes Base64-encoded JSON files. Because the code does not verify digital signatures or HMACs, it decodes and executes payload JSON values directly. Submit a base64-encoded JSON payload containing a key called cmd with a command like cat /app/flag.txt to extract the master flag!
