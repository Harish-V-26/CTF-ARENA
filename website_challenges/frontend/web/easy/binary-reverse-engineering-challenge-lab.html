Mission Briefing

AGENT, we have located an exposed staging application running a compiled ELF binary. We need you to perform a series of static and dynamic exploits against the target to extract the three hidden keys.

To capture all three secret flags, execute the following steps:

  • Binary Disclosure: Download the ELF binary from the server's /download route. Use static reversing tools (e.g. strings, objdump, Ghidra) to uncover the first flag.
  • Buffer Overflow: Audit the binary to find the buffer overflow threshold. Send a query parameter to the /bof route to trigger a crash and disclose the second flag.
  • LOLBins Command Execution: Bypass input restrictions on the /lolbin route using Living off the Land commands (like find or tar) to read the final flag file stored on the server.

Goal: Submit the final combined master flag, constructed in the format: FLAG{secret1_secret2_secret3} by concatenating the contents inside the braces of the three discovered flags.
