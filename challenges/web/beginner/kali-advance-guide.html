Kali Linux Advanced Commands Walkthrough

This guide serves as a comprehensive study sheet and practical instruction manual for the 70+ essential and advanced command-line utilities configured in your sandbox environment. Practice running these commands within your live attacker box container.

Connecting to the Live Sandbox

Once you click Launch Kali Machine ⇗ inside the room interface, copy the generated terminal connection command. It will look like this:

docker exec -it [container_id] bash

Open a terminal on your host machine, paste the command, and press Enter to drop directly into your live, isolated Kali Linux shell container.

1. Text Searching & Stream Manipulation

Master searching, slicing, translating, and redirecting data streams.

find

Locate files in a directory tree based on criteria like name, size, type, or permissions.

Find python files in /workspace 
find /workspace -type f -name "*.py"

grep

Global Regular Expression Print. Search files for matching text lines.

Search case-insensitively and recursively for "todo" 
grep -ri "todo" /workspace/text_processing/

xargs

Build and execute command lines from standard input streams.

Find all files ending in .conf and search them for DB_HOST config 
find /workspace -name "*.conf" | xargs grep "DB_HOST"

cut

Slices out sections from each line of files (columns/fields).

Extract the 2nd field of a comma-separated file 
cut -d',' -f2 /workspace/text_processing/employees.txt

sort & uniq

Organize data lines alphabetically or numerically, and remove duplicates.

Sort logs, extract IP addresses, and count unique occurrences 
cut -d' ' -f1 /workspace/text_processing/access.log | sort | uniq -c

tr

Translate, squeeze, or delete characters from standard input streams.

Translate lower to upper case 
cat file.txt | tr 'a-z' 'A-Z'

tee

Duplicate standard input, showing it on screen while saving it to a file.

Pipe output to screen and save file 
echo "test" | tee output.txt

2. Stream Editing & Structured Data Parsing

Advanced manipulation tools for configuration stream editing and JSON structures.

sed

Stream Editor. Used to perform basic text transformations on an input stream.

Replace "PORT=8080" with "PORT=9000" globally inline in a file 
sed -i 's/PORT=8080/PORT=9000/g' /workspace/text_processing/config/env/dev.conf

awk

Pattern scanning and processing language. Ideal for processing column/database styled text.

Print active employee names and salaries (columns 2 and 4) 
awk -F',' '$5 == "Active" {print $2 " earns $" $4}' /workspace/text_processing/employees.txt

jq

Command-line JSON processor. Slices, filters, maps, and transforms JSON data structures.

Extract a nested key value from api_response.json 
jq '.data.user.meta.api_token' /workspace/text_processing/api_response.json

3. Network Communication & Data Transfer

Utilities to fetch web pages, interact with sockets, and analyze traffic.

curl & wget

Transfer data from or to a server, or download files directly.

Retrieve response headers using curl 
curl -I http://target.local
Download a file using wget 
wget http://target.local/backup/config.bak -O /tmp/config.bak

ssh, scp & rsync

Secure connections, copying, and directory synchronization over SSH networks.

Login to SSH target machine 
ssh admin@target.local
Copy a local file to remote target machine 
scp local.txt admin@target.local:/tmp/
Synchronize a folder efficiently 
rsync -avz /workspace/text_processing/ admin@target.local:/tmp/sync_dir/

nc (Netcat) & socat

Establish raw network socket connections and create bidirectional traffic relays.

Connect to target port 4444 
nc target.local 4444
Relay incoming traffic on port 8080 to target.local port 80 
socat TCP4-LISTEN:8080,fork TCP4:target.local:80

tcpdump

Command line packet analyzer (sniffer) that prints network packets details on screen.

Sniff and display port 80 HTTP packet bodies in ASCII 
tcpdump -i eth0 -A 'port 80'

4. Network Reconnaissance & Troubleshooting

Inspect local network interfaces, open sockets, DNS, and path latency.

ss

Socket Statistics. Lists active TCP, UDP, raw, and Unix sockets, replacing older netstat.

Display all listening sockets with PIDs and numeric ports 
ss -tulpn

lsof

List Open Files. Linux treats sockets as files, so lsof lists processes using ports.

List processes listening on port 80 
lsof -i :80

dig

Domain Information Groper. Query DNS name servers for resource records.

Lookup domain records for target.local 
dig target.local ANY

ip

Show and manipulate routing, network devices, interfaces, and policy routing.

Show active network interface configurations 
ip addr show

traceroute & mtr

Trace routing pathways and run continuous ping latency checks to diagnostic destinations.

Trace network path 
traceroute target.local
Run interactive network path diagnosis 
mtr target.local

5. Process Control & Job Scheduling

Monitor resources, manage background jobs, terminate tasks, and schedule automation.

ps & htop

Inspect running processes via snapshots or dynamic real-time panels.

Print active process tree snapshot 
ps auxf

kill & pkill

Terminate processes using signals (default SIGTERM=15, force SIGKILL=9).

Force kill process by PID 
kill -9 1234
Kill processes by name matching 
pkill -f daemon_loop

jobs, bg, fg & nohup

Bash job control. Suspend, resume, background, and protect tasks from terminal hangups.

Run a process in the background 
sleep 100 &
Resume suspended job in background 
bg %1
Bring background job to foreground 
fg %1
Run task immune to session close 
nohup /workspace/network_practice/daemon_loop.sh &

watch & timeout

Repeated execution monitor and command execution duration enforcement limits.

Monitor file changes every 1 second 
watch -n 1 ls -l /workspace/text_processing/
Force command execution to terminate after 5 seconds 
timeout 5s ping target.local

cron & crontab

Schedule scripts to execute periodically in the background.

Edit cron schedules 
crontab -e

6. Binary Analysis & Low-Level Diagnostics

Decompile string assets, inspect byte codes, and trace process kernel system calls.

strings

Print the sequences of printable characters in files, especially compiled binaries.

Examine strings inside compiled security_scanner 
strings /workspace/binary_analysis/security_scanner

hexdump & xxd

Inspect raw binary files in hexadecimal representations and reverse hex formats.

Examine hexdump output of a file 
hexdump -C /workspace/binary_analysis/hex_raw.txt
Convert hex text back into a raw binary output 
xxd -r -p /workspace/binary_analysis/hex_raw.txt

base64

Encode and decode data using base64 representation standard.

Decode a base64 encoded text file 
base64 -d /workspace/binary_analysis/b64_encoded.txt

strace & ltrace

Monitor system calls (syscalls) and shared library calls triggered by processes.

Trace kernel actions for file openings or socket bindings 
strace /workspace/binary_analysis/security_scanner open_secret

7. Storage, Permissions, Services & Environment

Manage file system access, mount partitions, read kernel logs, and configure paths.

chmod, chown, getfacl & setfacl

Govern access controls. Read and write permissions (octal format like 600, 755) and fine-grained user ACLs.

Restrict file access to owner only 
chmod 600 secrets.txt
Check custom file access lists 
getfacl /workspace/file_management/permissions/shared.log
Grant read permission to specific user 
setfacl -m u:guest_operator:r /workspace/file_management/permissions/shared.log

tar, gzip & 7z

Archive and compress directories using zip, gzip, or 7z formats.

Extract a tarball archive 
tar -xzvf archive.tar.gz

mount, umount, lsblk, fdisk & parted

Inspect physical block storage devices, manage partition structures, and mount partitions.

Display active block storage device list 
lsblk

systemctl, journalctl & dmesg

Control systemd daemon services, inspect systemd logs, and view kernel buffer messages.

Display kernel messages 
dmesg | tail -n 20

history, alias, env, export & source

View shell command histories, define aliases, print variables, export properties, and evaluate files.

Create a permanent terminal command alias 
alias lsa="ls -lah"
export PATH="/workspace/bin:$PATH"

bash, python3, perl, git & docker

Interact with scripts, source control repositories, and launch containerized services.

Query docker container status from the Kali machine 
docker ps
