Kali Linux Advanced Commands Walkthrough

This guide provides a comprehensive cheatsheet and step-by-step instructions for utilizing the five foundational command-line security tools loaded in your Kali Linux Attack Box sandbox.

Connecting to the Live Sandbox

Once you click Launch Kali Machine ⇗ inside the room interface, copy the generated terminal connection command. It will look like this:

docker exec -it [container_id] bash

Open a terminal on your host machine, paste the command, and press Enter to drop directly into your live, isolated Kali Linux shell container.

1. Nmap — Network Port Scanning

Use Nmap to discover open TCP ports, versions of running software, and target operating systems.

Basic SYN Stealth Scan + OS Fingerprint 
nmap -sS -sV -O <target_ip>
  • -sS: Tells Nmap to perform a TCP SYN stealth scan.
  • -sV: Tells Nmap to probe ports and retrieve service banner versions.
  • -O: Triggers operating system stack detection.

2. Dirb — Directory and File Bruteforcing

Use Dirb to scan target web servers for hidden directories, files, or admin panels using a dictionary list.

Simple Path Fuzzing Scan 
dirb http://<target_ip> /usr/share/wordlists/dirb/common.txt
  • /usr/share/wordlists/dirb/common.txt: The default built-in wordlist file loaded in Kali Linux.
  • Look for entries showing status code 200 OK or 403 Forbidden.

3. Sqlmap — Automated SQL Injection Tool

Scan parameters inside URLs to automatically check for SQL vulnerabilities and extract data tables.

Enumerate Databases 
sqlmap -u "http://<target_ip>/item.php?id=1" --dbs
Dump Target Table Columns & Rows 
sqlmap -u "http://<target_ip>/item.php?id=1" -D database_name -T users --dump
  • -u: Pass the URL parameter container to test.
  • --dbs: Discover available database structures.
  • --dump: Download database content directly to the terminal.

4. Hydra — Network Password Cracking

Perform high-speed multi-threaded brute-forcing against login services like SSH or FTP.

Crack SSH Passwords 
hydra -l admin -P /usr/share/wordlists/rockyou.txt ssh://<target_ip>
  • -l: Specifies a single static username (e.g. admin).
  • -P: Points to the famous rockyou.txt wordlist containing millions of passwords.
  • ssh://: Tells Hydra to target the SSH service running on port 22.

5. Netcat (nc) — Raw Network Socket Utility

Read, write, and listen across network connections. Perfect for simple connection testing or receiving reverse shell links.

Start Listener on Port 4444 
nc -lvp 4444
Connect / Grab Banners on Web Server Port 80 
nc <target_ip> 80
  • -l: Listen mode.
  • -v: Verbose output.
  • -p: Port specification.
