Pure CTF Challenge

Operation Shadow Gate

Infiltrate NEXUS CORP and recover the master flag.

Mission Briefing

AGENT, your target is a live NEXUS CORP server running within an isolated Docker environment. Intelligence indicates that a highly classified master flag is hidden somewhere within the system's internal filesystem (specifically in the /tmp directory).

Unlike standard training labs, there is no guide here. You must independently use the knowledge acquired from your previous training to compromise the server.

To succeed, you will need to perform a complete attack chain:

  • Nmap Reconnaissance: Map the attack surface and discover vulnerable services.
  • Brute Force: Crack weak authentication mechanisms.
  • SQL Injection: Extract sensitive backend data.
  • XSS: Exploit client-side trust.
  • Metasploit: Gain remote code execution and a Meterpreter shell to read the flag.
