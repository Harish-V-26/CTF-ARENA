Mission Briefing

AGENT, your target is a live NEXUS CORP server running within an isolated Docker environment. Intelligence indicates that a highly classified master flag is hidden somewhere within the system's internal filesystem (specifically in the /tmp directory).

Unlike standard training labs, there is no guide here. You must independently use the knowledge acquired from your previous training to compromise the server.

To succeed, you will need to perform a complete attack chain:

  • Nmap Reconnaissance: Map the attack surface (specifically scanning simulated FTP and SSH services).
  • DevTools Analysis: Audit client-side DOM structure/source code for comments.
  • Brute Force: Crack weak credentials on the administrative login page.
  • SQL Injection: Inject UNION queries to extract secret keys from the SQLite catalog database.
  • XSS (Stored): Deliver a guestbook comment containing executable scripting.
  • Insecure Direct Object Reference (IDOR): Guess sequential identifiers to read confidential admin invoices.
  • Command Injection / Metasploit: Exploit OS shell diagnostic interfaces to obtain target system files.
