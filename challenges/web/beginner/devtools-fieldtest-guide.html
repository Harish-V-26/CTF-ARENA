Introduction

How the practical labs work

Welcome to the practical side of CTF LABS! In this lab, you'll be using Developer Tools (DevTools) built into your browser to search for three pieces of a secret flag hidden across Inspector, Network headers, and JavaScript source code.

Part 1

The Inspector Hunt

  • Step 1 Open Elements. Open Developer Tools in your browser (F12 or Ctrl+Shift+I / Cmd+Option+I) and switch to the Elements (or Inspector) tab.
  • Step 2 Search. Press Ctrl+F to open the search bar within the DOM and type the word flag.
  • Step 3 Find Part 1. Look through the search results until you find an HTML comment <!-- -->. You will find Part 1 hidden in the comment: flag_part1{dev_tools_

Part 2

The Network Detective

  • Step 1 Go to Network Tab. Go to the Network tab in Developer Tools. Refresh the page (F5 or Ctrl+R) to capture all network traffic.
  • Step 2 Find Failed Request. You will see several requests. Notice that one request for an image fails with a 404 Not Found error status. Click on it.
  • Step 3 Find Part 2. Look at the Response Headers section. Look for a custom HTTP header starting with "X-". You will find the header X-Flag-Part2. Its value is Part 2: power_

Part 3

The Source Code Spy

  • Step 1 Go to Sources Tab. Go to the Sources (or Debugger) tab in Developer Tools.
  • Step 2 Search Code. Open the file named app.js (or similar). Look through the code or press Ctrl+F within the file to search for "flag" or "final".
  • Step 3 Find Part 3. You will find a hardcoded variable named finalPiece containing the last part of the flag. The value of this variable is Part 3: user}
  • Step 4 Combine the Pieces. Combine all three parts together to form the complete flag:
    Part 1 + Part 2 + Part 3 = flag_part1{dev_tools_power_user}
