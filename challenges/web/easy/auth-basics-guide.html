Introduction

How the practical labs work

Welcome to the practical side of CTF LABS! In this lab, you'll be using Developer Tools (DevTools) to analyze login flows, extract session cookies, and decode JSON Web Tokens (JWT).

Part 1

Login Analysis

  • Step 1 Open DevTools. In the target tab, open DevTools (F12) and go to the Network tab.
  • Step 2 Invalid Login. Submit the form with bad credentials (e.g., test/test). The Network request will return a 401 Unauthorized status code.
  • Step 3 Valid Login. Log in using admin / admin123. The Network request will return a 200 OK status code.

Part 2

Exploring Cookies

  • Step 1 Go to Application Tab. Navigate to the Application tab (Chrome) or Storage tab (Firefox) in DevTools.
  • Step 2 Find Cookies. Expand "Cookies" and click your domain.
  • Step 3 View Tokens. You will see the server set session_id and auth_token cookies.

Part 3

Decoding JWT

  • Step 1 Copy Token. Copy the value of the auth_token cookie.
  • Step 2 Decode. Go to jwt.io and paste the token.
  • Step 3 Find Flag. In the decoded Payload section on the right, you will see the secret flag: flag{jwt_m4st3r_decoded}.
