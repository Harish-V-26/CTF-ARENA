Introduction

How the practical labs work

Welcome to the practical side of CTF LABS! In this lab, you'll be using the Nmap tool to scan a target container, find a hidden port, and extract a secret flag.

Part 1

Nmap Scanning

  • Step 1 Start Containers. Click "Launch Target Server" and "Start Kali Container". Connect to the Kali container using your host terminal: docker exec -it [id] bash.
  • Step 2 Full Port Scan. In Kali, run a full port scan on all 65,535 ports to find the hidden backdoor:
    nmap -p- host.docker.internal
    Notice the secret 5-digit port (e.g., 31337).
  • Step 3 Version Detection. Run a version detection scan targeting only that specific secret port to force it to reveal the flag:
    nmap -sV -p 31337 host.docker.internal
  • Step 4 Claim Flag. Look closely at the service version output. The flag will be printed right there: CTF{n4v1g4t1ng_p0rts_w1th_nm4p}.
