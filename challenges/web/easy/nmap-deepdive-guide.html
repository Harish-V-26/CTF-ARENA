Introduction

Beyond the basics

While basic SYN and Connect scans are great for standard reconnaissance, modern networks deploy firewalls and Intrusion Detection Systems (IDS) that can easily detect and block these probes. In this guide, we dive deep into the advanced features of Nmap designed to bypass these defenses and extract sensitive information using automated scripts.

🕵️

Stealth Scans

Exploiting the TCP RFC

  • Step 1 Understand the theory: If a packet without standard connection flags (SYN, ACK) is sent to an open port, the port ignores it. If sent to a closed port, the port responds with a Reset (RST). We can use this to map out listening services.
  • Step 2 Null Scan: Send a packet with no flags set.
    nmap -sN host.docker.internal
  • Step 3 FIN Scan: Send a packet with only the FIN flag set.
    nmap -sF host.docker.internal
  • Step 4 Xmas Scan: Light the packet up like a Christmas tree by setting FIN, PSH, and URG.
    nmap -sX host.docker.internal
  • Note These scans bypass simple stateless firewalls but are often ineffective against Windows targets.
🛡️

Firewall Evasion

Fragmentation, Decoys, and Spoofing

  • Fragmentation Split packets into tiny chunks to confuse IDS signatures. Use -f for 8-byte chunks, or -ff for 16-byte chunks.
    nmap -f host.docker.internal
  • Decoys Hide your real IP by spoofing dozens of fake source IPs alongside your own.
    nmap -D RND:10 host.docker.internal
📜

Nmap Scripting Engine

Automating enumeration

  • Step 1 The NSE allows you to run Lua scripts to automate tasks like vulnerability checking and brute forcing. Scripts are found in /usr/share/nmap/scripts/.
  • Step 2 To test a specific service, like checking if an FTP server allows anonymous login, use the --script flag.
    nmap --script ftp-anon -p 2121 host.docker.internal
🏁

Capture the Flag

Combine your skills

  • Step 1 Start the Deep Dive Target container and Kali container from the lab interface.
  • Step 2 Connect to the Kali terminal and scan all ports to discover hidden services:
    nmap -p- host.docker.internal
  • Step 3 You will find ports 2121 (FTP) and 54321 (Secret Server) open. Since you only have Nmap tools available, use the banner grabbing script to extract the first flag from the FTP server:
    nmap -p 2121 --script banner host.docker.internal
  • Step 4 Use Nmap's banner script to connect to the high-security port and retrieve the second part of the flag:
    nmap -p 54321 --script banner host.docker.internal
  • Step 5 Combine Flag Part 1 and Flag Part 2 into the format CTF{...} and submit it to complete the lab!
