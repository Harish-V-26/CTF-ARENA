Introduction

How the practical labs work

Welcome to the practical side of CTF LABS! In this lab, you'll be using Developer Tools (DevTools) to manipulate URLs and intercept network requests to escalate your privileges.

Part 1

The Leaked Invoice

  • Step 1 Log In. Launch the lab and log in using the credentials employee_john / password123.
  • Step 2 View Invoice. Click "View Details" on Invoice #1001. Notice the URL ends in /invoice/1001.
  • Step 3 Tamper URL. Change the number in the address bar to 1002, 1003, etc., to view other users' invoices. One of them contains the hidden flag: CTF{ID0R_1nv0ic3_l34k}.

Part 2

Mass Assignment

  • Step 1 Open Profile. Go to the Profile page and open Developer Tools (F12) to the Network tab.
  • Step 2 Trigger Request. Change your email and click Save. Find the update_profile request in the Network tab to see its JSON payload.
  • Step 3 Execute Custom Request. Go to the Console tab and paste this script to inject the role: "admin" field:
    fetch("/api/update_profile", { method: "POST", credentials: "include", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ user_id: "1", email: "hacker@test.com", role: "admin" }) }).then(r => r.json()).then(d => { console.log(d); alert("Done! Refresh the page."); });
  • Step 4 Claim Flag. Refresh the page. Your role is now admin! Visit the Admin Panel to claim the flag: CTF{ID0R_pr1v_3sc_4dm1n}.
