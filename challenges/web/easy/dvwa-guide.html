Introduction

How the practical labs work

Welcome to the practical side of CTF LABS! Unlike the beginner quizzes, the Easy Level challenges require you to attack real, running servers. To do this safely, our platform uses Docker to instantly spin up isolated, private lab environments specifically for you.

Damn Vulnerable Web App (DVWA)

Step-by-step for absolute beginners

  • Step 1 Open the Magic Box. Click the red "Launch DVWA Instance" button on the lab page. Think of it like turning on a tiny, private computer just for you. A new tab will open automatically.
  • Step 2 Log in like a Boss. The website asks for a name and password. Type Username: admin and Password: password. It's like having the master key! Once inside, scroll down and click "Create / Reset Database" to set everything up.
  • Step 3 Let's Break Things! (Low Difficulty). On the left side, click on Command Injection. You'll see a box where you can type an IP address to "ping" it. But this box has a secret: if you type a semicolon ;, it lets you run hidden hacker commands!
  • Step 4 The Magic Spell. Type this exactly: 127.0.0.1; ls -la and hit Submit. What happens? The website first pings the IP, and then the ls -la part tells the computer to "list all your hidden files." Boom! You just tricked the server into doing what you want!
  • Step 5 Read Secret Files. Now try typing 127.0.0.1; cat /etc/passwd. The cat command means "read this file". You just read the list of all users on the server. You are officially hacking!

The "Impossible" Difficulty

Why can't we hack it anymore?

If you go to the DVWA Security tab on the left side of the app, you can change the difficulty from "Low" all the way up to "Impossible".

What happens on Impossible mode?
When you set it to Impossible, the app becomes totally secure. If you try our magic trick (127.0.0.1; ls -la), it won't work anymore! The website will just say "ERROR".

Why is it Impossible? (Explained simply)
Imagine you have a bouncer at a club. On "Low" difficulty, the bouncer is asleep, so anyone can walk in (even our sneaky ; ls -la command). But on "Impossible" difficulty, the bouncer is wide awake and checking IDs very strictly.

The code on Impossible mode looks exactly at what you typed and says: "Wait a minute! An IP address should only have numbers and dots (like 127.0.0.1). What is this semicolon (;) doing here? That's not allowed!"

It completely stops the attack before it even reaches the server. This is called Input Validation, and it's the best way to keep hackers out!
