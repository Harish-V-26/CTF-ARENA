What is SQL Injection? 10 pts
📖 Reading — Learn the concept first
SQL (Structured Query Language) is used to communicate with databases. Websites use SQL to store and retrieve data like usernames, passwords, and articles. A typical login query looks like this: SELECT * FROM users WHERE username = 'john' AND password = 'secret123'; SQL Injection (SQLi) is a vulnerability that occurs when user input is directly inserted into a SQL query without proper sanitisation. An attacker can inject SQL commands to manipulate the query's behaviour. The most basic SQLi test uses a single quote (') to break out of the string. If the application returns an error, it might be vulnerable. Example: Username: admin' -- Password: anything The -- is a SQL comment. Everything after it is ignored. The resulting query becomes: SELECT * FROM users WHERE username = 'admin' -- ' AND password = 'anything' This bypasses the password check and logs in as admin. Common SQL comment symbols: -- (double dash) → SQL comment in most databases # (hash) → MySQL comment /**/ (slash-star) → Multi-line comment

📖 Reading — Learn the concept first
The UNION operator in SQL combines results from two or more SELECT queries. Attackers use UNION to extract data from other tables in the database. UNION syntax: SELECT column1, column2 FROM table1 UNION SELECT column1, column2 FROM table2 For UNION to work, both SELECT statements must return the same number of columns. Attackers find the column count using ORDER BY or GROUP BY: ' ORDER BY 1 -- (works) ' ORDER BY 2 -- (works) ' ORDER BY 3 -- (error → only 2 columns) Once the column count is known, the attacker extracts data: ' UNION SELECT username, password FROM users -- Common tables to target: - users → usernames and passwords - admins → admin credentials - sessions → active session tokens Passwords are sometimes stored as hashes (not plain text). Common hash types: - MD5 → 32 hex characters - SHA1 → 40 hex characters - SHA256 → 64 hex characters - bcrypt → starts with $2y$
