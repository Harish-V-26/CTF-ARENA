Introduction

Python as an Offensive Tool

Whether you want to automate web application enumeration, build a custom exploit, or parse log files, Python makes scripting straightforward. In this lab, we build tools from scratch rather than relying on heavy frameworks.

Python Basics

Data types and conversion

  • Step 1 Learn how variables are defined dynamically without type keywords. Use print() to output data, and wrap strings inside f-strings for clean variable embedding (e.g. f"Host: {ip}").
  • Step 2 Understand data type conversion. Python requires explicit conversion when concatenating incompatible types (e.g., using str(port)).

Socket Port Scanner

Checking if ports are open

Using standard socket libraries, we check if ports are accepting connections.

  • Step 1 Import the socket module:
    import socket
  • Step 2 Instantiate a stream socket using socket.socket(socket.AF_INET, socket.SOCK_STREAM).
  • Step 3 Run connect_ex((ip, port)). A return status of 0 signifies that the port is open. Any other integer signifies that the port is closed or blocked.

HTTP & Web Requests

Querying paths and looking at status codes

Web directories and files can be fuzzed using Python requests.

  • Step 1 Import requests to interact with web targets:
    import requests
  • Step 2 Run requests.get("http://URL") and check the status_code. If it equals 200, the page exists. If it equals 404, the page does not exist.

Credentials Brute Force

Submitting credential parameters via POST

  • Step 1 Analyze the request body parameters for the login form (e.g. username and password).
  • Step 2 Construct a dictionary payload containing candidate credentials and post them:
    r = requests.post(url, data={'username': 'admin', 'password': 'candidate_password'})
  • Step 3 Inspect r.text for indicators of successful login, or check the status code (e.g. 200 OK vs 401 Unauthorized).

Python Reverse Shells

Network streams and subprocess redirection

A reverse shell establishes an outbound socket connection back to the listening attacker machine.

  • Step 1 Create a socket connection to the attacker's listener IP and port.
  • Step 2 Use os.dup2() to clone standard input, output, and error streams onto the socket file descriptor.
  • Step 3 Launch an interactive shell (e.g. /bin/sh -i) using subprocess.call(). Any commands typed on the attacker listener will now execute on the victim machine.

Capture the Flag

Attack target and retrieve the flag

  • Step 1 Launch the Target Server and the Kali Linux Attack Box using the dashboard controls. Note the dynamic target port shown on the dashboard.
  • Step 2 Inside the Kali machine terminal, test connection using:
    curl http://host.docker.internal:PORT/
  • Step 3 Inspect the target's /robots.txt file in your browser or with curl to find the hidden path:
    curl http://host.docker.internal:PORT/robots.txt
    This reveals the disallowed directory path.
  • Step 4 Write or copy-paste a python script inside the Kali environment to brute force the credentials on the administrative page (e.g., /admin-login) using the wordlist. Test the password list: ['admin', '123456', 'password', 'pypower', 'letmein'].
  • Step 5 Submit the discovered password and flag in the challenge's quiz to complete the lab!

Frequently Asked Questions

Why does requests.post return a 401 status?
A 401 Unauthorized status indicates that the username/password combination sent in the payload was incorrect. Continue iterating through your password list until you receive a 200 OK success response.
