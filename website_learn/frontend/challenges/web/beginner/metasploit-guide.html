Introduction

How the practical labs work

Welcome to the practical side of CTF ARENA! The Metasploit Introduction challenge requires you to attack a real, running server. To do this safely, our platform uses Docker to instantly spin up isolated, private lab environments specifically for you.

Metasploit Target

Using Kali Linux & Metasploit

  • Step 1 Start the Target and Kali. Go to the Metasploit Lab page. Click "Launch Target Server" and "Start Kali Container". Wait for both to spin up. Note the IP address given in the Target Server panel.
  • Step 2 Connect to Kali. Copy the displayed command (e.g., docker exec -it [id] bash) and paste it into your local computer's terminal. You are now inside Kali!
  • Step 3 Launch Metasploit Console. Inside the Kali terminal, type:
    msfconsole
    Wait for the msf6 > prompt.
  • Step 4 Search and Use the FTP Scanner. We need to find the FTP version scanner. Type:
    search ftp use auxiliary/scanner/ftp/ftp_version
  • Step 5 Set Options and Exploit. Set the RHOSTS to your Target Server's IP, then run the exploit:
    set RHOSTS <Target-IP-Address> run
    The scanner will connect to the target FTP server and grab its banner. The secret flag will be returned in the banner message!

Frequently Asked Questions

What is the RHOSTS option?
RHOSTS stands for "Remote Hosts" and is the IP address of the target you want to attack.

Do I need to stop my containers?
Our backend automatically shuts down your Docker containers when you click the "Stop" buttons or simply close your browser tab! This ensures your computer doesn't run out of memory.
