Introduction

How the practical labs work

Welcome to the practical side of CTF ARENA! In this lab, you'll be using Developer Tools (DevTools) built into your browser to manipulate the DOM, reveal hidden elements, and extract local storage secrets.

Challenge 1

The Console Trick

  • Step 1 Open DevTools. Open Developer Tools in your browser (F12 or Ctrl+Shift+I / Cmd+Option+I).
  • Step 2 Go to the Console. Switch to the Console tab.
  • Step 3 Enable the Button. The button has the ID `flagBtn`. You can enable it by modifying its DOM property using JavaScript. Run this command:
    document.getElementById('flagBtn').disabled = false
  • Step 4 Click the Button. The button will now become clickable. Click it to reveal the flag: flag{...}.

Challenge 2

The Hidden Element

  • Step 1 Go to Elements. In Developer Tools, go to the Elements (or Inspector) tab.
  • Step 2 Search DOM. Press `Ctrl+F` (or `Cmd+F` on Mac) while focused in the Elements tab to open the search bar.
  • Step 3 Find the Flag. Search for the word "flag". You will find a `div` element with `id="hidden-flag-div"`. Inside it, you will see the flag: flag{...}.

Challenge 3

The Storage Secret

  • Step 1 Go to Application Tab. In Developer Tools, go to the Application tab (Chrome/Edge) or Storage tab (Firefox).
  • Step 2 Expand Local Storage. In the left sidebar, expand the Local Storage section and click on the domain of the current page.
  • Step 3 Find the Flag. Look for the key `secret_flag`. The value next to it is your flag: flag{...}.
