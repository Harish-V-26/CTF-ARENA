01 The Console Trick

Locked
Scenario

The button below is disabled — it's grayed out and you can't click it. But front-end restrictions are just suggestions. Your mission: use the Console to enable the button and click it to reveal the flag.

Live Sandbox

This button is locked by JavaScript. Can you unlock it?

Step-by-Step Guide
  1. Right-click the "Locked" button above and select Inspect.
  2. Look at the button's code: <button id="flagBtn" disabled>
  3. Switch to the Console tab (Ctrl+Shift+J).
  4. Type: document.getElementById('flagBtn').disabled = false and press Enter.
  5. The button is now active! Click it to reveal the flag.
You can also do it directly in the Inspector: find the word disabled in the HTML tag and simply delete it!

02 The Hidden Element

Locked
Scenario

This sandbox looks empty — just a boring message. But there's a hidden HTML element on this page containing a flag. Your mission: use the Inspector to find the hidden element and reveal it.

Live Sandbox

Nothing to see here... or is there?

flag{inspector_dom_master}

Step-by-Step Guide
  1. Open DevTools (F12) and go to the Inspector / Elements tab.
  2. Press Ctrl+F inside the Inspector and search for flag.
  3. You'll find: <div id="hidden-flag-div" style="display:none">
  4. The flag text is inside that div! Copy it.
  5. Bonus: Change display: none to display: block to see it on the page.
Try typing this in the Console: document.getElementById('hidden-flag-div').textContent

03 The Storage Secret

Locked
Scenario

This page stored a secret in the browser's memory when it loaded. The page doesn't display it anywhere. Your mission: use the Storage / Application panel to find the hidden flag in LocalStorage.

Live Sandbox

Data has been stored... somewhere.

The flag was silently written to your browser when this page loaded. Can you find where?

Step-by-Step Guide
  1. Open DevTools (F12) and go to the Application (Chrome) or Storage (Firefox) tab.
  2. Expand Local Storage in the left sidebar.
  3. Click on the current domain to view stored key-value pairs.
  4. Find the key named secret_flag — the value is your flag!
  5. Alternative: In the Console, type localStorage.getItem('secret_flag').
Also check document.cookie — there might be bonus data in cookies too. But the main flag is in LocalStorage under the key secret_flag.
